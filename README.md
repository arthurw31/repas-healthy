# 🥗 Repas Healthy

App d'inspiration pour repas sains, basée sur mes listes d'idées (protéines, sauces, féculents, légumes, plats complets, entrées, desserts).

## Fonctionnalités

- **🎲 Inspiration** — générateur d'idées avec 3 modes :
  - *Assiette composée* : protéine + préparation + féculent + légume + façon de cuisiner le légume + sauce
  - *Plat complet* : un plat + un dessert
  - *Menu entier* : entrée/apéro + plat + dessert
  - Chaque élément peut être verrouillé 🔒 ou relancé 🔄 individuellement
- **📅 Ma semaine** — génère un planning de 7 dîners sans répétition, avec verrouillage jour par jour
- **⭐ Favoris** — garde les combos qui te plaisent
- **📚 Bibliothèque** — toutes les listes sont modifiables (ajout / suppression / réinitialisation), sauvegardées dans le navigateur (localStorage)

## Technique

Une seule page statique (`index.html`), sans dépendance ni build. Il suffit d'ouvrir le fichier dans un navigateur, ou de servir le repo via GitHub Pages.
